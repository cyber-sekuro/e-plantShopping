# e-plantShopping — Paradise Nursery Shopping Application

## Project Overview

Paradise Nursery is a React-based online plant shopping application developed for the IBM Full Stack Software Developer Professional Certificate.

The application allows customers to browse different categories of plants, add products to a shopping cart, adjust quantities, remove items, and calculate the total purchase amount.

## Technologies Used

- React.js
- JavaScript (JSX)
- Redux Toolkit
- React Redux
- HTML5 and CSS3
- Vite
- Git and GitHub
- GitHub Pages

## Features

- Landing page introducing Paradise Nursery
- Five plant categories with images, descriptions, and prices
- Add to Cart functionality
- Dynamic shopping-cart item counter
- Redux-based cart state management
- Increase and decrease product quantities
- Remove products from the shopping cart
- Individual product subtotals and overall cart total
- Continue Shopping navigation
- Checkout button displaying a Coming Soon message

## Local Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build the application:

```bash
npm run build
```

## Project Purpose

This project demonstrates frontend development using React components, hooks, event handling, JavaScript arrays, and Redux Toolkit for application state management.
